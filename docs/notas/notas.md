# Termos

**XML** — *Extensible Markup Language*. Linguagem de marcação padronizada pela W3C, usada para compartilhamento fácil de informações pela internet e para arquivos de configuração (no nosso caso).

**DTO** - *Data Transfer Object*. Um objeto que só serve para transferir dados, não são entidades no database ou na aplicacao. existem apenas em momentos de transicao de dados. **(Ex.: Um request que precisa apenas de alguns campos especificos: ver [RecusaRequest.java](../../backend/src/main/java/com/hemotrack/backend/model/requisicao/dto/RecusaRequest.java).)**
